!!! Note

    Jede Steuerregel, die sie einem Produkt zuweisen, müssen Sie zuerst erstellen.
    Wenn mehrere verschiedene Steuersätze auf Ihre Produkte zutreffen, dann erstellen Sie eine Steuerregel für jeden davon.
    Wenn Sie Produkte mit einem Steuersatz von 0 % verkaufen (wie z.B. [Wertgutscheine](../../guides/gift-cards.de.md)), dann müssen Sie trotzdem zuerst eine Steuerregel von 0 % anlegen.
    Für mehr Informationen lesen Sie unseren Guide zum Anlegen von [Steuerregeln](../../guides/taxes.de.md#steuer-regeln-erstellen).
